# Burrows-Wheeler Transform in Python

This personal project is an introduction to the Burrows-Wheeler Transform (BWT), a method of rearranging text that can make it easier to compress. The program asks the user for a word, adds `$` as an end-of-text marker, and displays rotations of the resulting string.

V1.0:
The current version focuses on illustrating this rotation step. A complete BWT also sorts the rotations and takes the last character from each row to produce the transformed text.
